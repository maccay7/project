Debug Preview Function

Open browser console (F12) and click the eye icon in the upload page to see debug messages.

What to look for in console:

  • previewFile called with index: - Should show when eye icon is clicked
  • uploadedFiles: - Should show the uploaded files array
  • Selected file: - Should show the file being processed
  • dataAPI.upload called with: - Should show the API call details
  • apiRequest called: - Should show the HTTP request details
  • API response status: - Should show 200 for success
  • API response data: - Should show the returned data
  • Preview data loaded: - Should show number of rows loaded

Common Issues:

  • No console messages: - Eye icon click event not working
  • CORS errors: - Backend not running or CORS issues
  • Network errors: - Backend endpoint not accessible
  • File processing errors: - Backend can't process the file
