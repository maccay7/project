ABSTRACT
This project presents the design and development of a web-based prototype system called Automation of Financial Instruments Valuation, developed to automate the valuation of financial instruments. Traditional spreadsheet-based valuation methods used in many financial institutions are often inefficient, error-prone, and difficult to manage, especially when handling large datasets and complex financial calculations.
The developed system allows users to securely log in, upload financial datasets, and automatically generate financial instrument valuations. The system also provides dashboards and visualizations to support the analysis and interpretation of results. In addition, automated report generation features enable users to quickly produce structured valuation reports, improving efficiency, accuracy, and transparency in financial processes.
The system was designed using Figma for interface prototyping and MySQL Workbench for database modeling, while modern web technologies supported implementation. The outcome is a functional prototype that demonstrates how automation can improve financial valuation processes and support better decision-making in financial institutions.

CHAPTER 1: INTRODUCTION AND BACKGROUND
1.1 Background and Motivation
Financial institutions operate in data-driven environments where accuracy, efficiency, and timely reporting are important. Treasury and investment departments manage financial instruments such as Treasury Bills, Bonds, and Money Market instruments, which require regular valuation for decision-making and reporting purposes.
Traditionally, many organizations use spreadsheet tools such as Excel for valuation processes. However, as datasets become larger and more complex, spreadsheet-based methods become inefficient, difficult to manage, and prone to errors. Manual data cleaning, formula entry, and report preparation increase the risk of inconsistencies and reduce productivity.
Another challenge is the lack of automated visualization and reporting tools, forcing users to manually create charts and summaries. To address these challenges, this project proposes a web-based system called Automation of Financial Instruments Valuation. The system allows users to securely log in, upload datasets, automatically clean datasets, automatically generate valuations, view visualizations, and produce reports in a structured and efficient manner.
1.2 Problem Identification
The current valuation process for financial instruments relies heavily on spreadsheets and manual operations. Although spreadsheets are widely used, they become inefficient and error-prone when handling large datasets and complex calculations.
Data cleaning, preparation, and valuation calculations are performed manually, increasing the risk of human error and reducing efficiency. In addition, report preparation and data visualizations are manually created, which consumes time and may lead to inconsistencies in reporting.
The proposed system, Automation of Financial Instruments Valuation, addresses these challenges by automating dataset upload, cleaning, valuation calculations, visualization generation, and report generation. This improves accuracy, efficiency, and productivity in financial valuation processes.
1.3 Objectives

3.2 Weaknesses of the Current System
Limited single source of truth for instrument terms and valuations.
Weak version control on assumptions embedded in spreadsheet cells.
Manual copy-paste into reports increases error rates.
Audit trails are fragmented (email timestamps vs. cell history).
Scaling to multiple analysts introduces merge conflicts and inconsistent files.
3.3 Requirements Analysis
3.3.1 Functional Requirements
Users shall authenticate using email and password.
Authenticated users shall view portfolio statistics and instrument lists.
Users shall upload CSV/XLSX files with metadata and receive structured previews and cleaning summaries.
The system shall store upload metadata and maintain audit logs.
Users shall view reports and export them in CSV, JSON, or HTML formats.
The system shall provide REST APIs for dashboards, instruments, uploads, and reports.
3.3.2 Non-Functional Requirements
Usability: Responsive interface with clear navigation and workflow.
Security: HTTPS, token-based authentication, and password hashing.
Performance: Paginated data handling and controlled file upload sizes.
Maintainability: Modular frontend structure with extensible backend design.
Reliability: Database health checks and structured error handling.

CHAPTER 5: IMPLEMENTATION AND TESTING
5.1 Introduction
This chapter presents the implementation and testing of the Automation of Financial Instruments Valuation System. The implementation phase focused on developing a web-based platform that automates the valuation of selected financial instruments, namely Treasury Bills, Money Market Instruments, and Bonds. The system was designed to improve efficiency, accuracy, and consistency in the valuation process by reducing reliance on manual calculations.
To ensure that the developed system met its functional and non-functional requirements, various testing techniques were employed. Authentication testing and input validation testing were conducted to verify system security and data integrity. Unit testing was performed using pytest, API testing was conducted using Postman, and performance testing was carried out using Apache JMeter. The chapter also discusses system deployment and maintenance procedures.
5.2 System Implementation
The Automation of Financial Instruments Valuation System was developed using the Django framework and Python programming language. The system architecture integrates valuation models, database management, user authentication, reporting functionalities, and dashboard visualizations into a single platform.
The implementation process involved developing modules responsible for instrument management, valuation calculations, user management, report generation, and data storage. These modules interact to provide users with automated valuation results based on instrument-specific parameters and market information.
The system allows users to perform valuations for Treasury Bills, Money Market Instruments, and Bonds through an intuitive web interface. The implementation also included search functionalities, dashboard analytics, and automated report generation to enhance usability and decision-making.
